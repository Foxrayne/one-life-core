3. LOCAL DATA

The launcher reads Project Zomboid's locally saved server list so it can show
your server profiles. Launcher preferences are stored under your local
Zomboid/storm/launcher directory. Account and server passwords remain in the
game's own local saved-server database. The launcher also writes local logs
to help diagnose launch problems.

4. NETWORK ACTIVITY

The launcher contacts Steam and the selected Project Zomboid server when you
ask it to update mods, query a server or connect. Clicking the Discord link
opens the One/Life invite in your normal browser.

The branded launcher does not upload logs, diagnostics, analytics or
telemetry. Storm startup analytics are not registered in this distribution.

The launcher does not self-update from Storm's upstream launcher service.
The underlying unmodified Storm core may check Storm's public update service
for compatible core releases. This allows One/Life Core to receive upstream
engine fixes without replacing the One/Life launcher or its branding.

5. SERVER DATA

When you connect to One/Life, the game server necessarily receives your
network address, Steam identity, in-game account information and gameplay
data. Server-side data is governed by the One/Life community rules and
notices available through the Discord above.
